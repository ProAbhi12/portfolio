# Abhisekh Shakya — Portfolio

Personal portfolio of Abhisekh Shakya, Full-Stack Developer at Aster Innovations, Lalitpur, Nepal.

Built with React, Vite and GSAP. Typography: Clash Display (hero) and General Sans (UI), self-hosted.

## Run locally

    npm install
    npm run dev

## Build

    npm run build

Output lands in `dist/`, ready for any static host. Deployment steps for
Cloudflare Pages and the abhisekhshakya.com.np domain live in `DEPLOY.md`.
